# Kids Calculator App

A colorful calculator built for kids with large number buttons and simple math actions.

## Run it locally

Open the project folder in a browser, or use a local web server:

```bash
cd d:\Nota
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Simple addition, subtraction, multiplication, and division
- Large, friendly buttons for children
- Clear and delete controls
- Bright, cheerful design
